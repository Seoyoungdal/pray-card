# 기도카드 (Prayer Card) PWA

매일의 기도를 기억하는 오프라인 지원 기도 카드 저널 앱입니다.

## 주요 기능

- **오늘의 말씀**: 날짜 기반 성경 구절 (기본 제공 + 사용자 업로드)
- **오늘의 기도**: 체크하면 "오늘 기도 완료"로 이동, 다음날 자동 복귀
- **공동체 기도**: URL 또는 파일로 가져오기 (중복 자동 제외)
- **카테고리**: 자유롭게 추가/삭제
- **다크모드**: 시스템 설정 자동 따름
- **완전 오프라인**: 설치 후 인터넷 없이 사용 가능
- **데이터 백업**: JSON 내보내기

## GitHub Pages에 배포하는 방법

1. GitHub에 새 저장소 생성 (예: `prayer-card`)
2. 이 폴더의 모든 파일을 업로드
3. 저장소 **Settings → Pages** 로 이동
4. Source를 `Deploy from a branch` → `main` / `/ (root)` 선택
5. 저장 후 1~2분 뒤 `https://<username>.github.io/prayer-card/` 로 접속

## 홈 화면에 설치 (PWA)

- **안드로이드**: Chrome에서 접속 → 메뉴 → "홈 화면에 추가"
- **아이폰**: Safari에서 접속 → 공유 버튼 → "홈 화면에 추가"

## 공동체 기도 파일 형식

**텍스트 (.txt)**
```
가족 건강을 위해
교회 부흥을 위해
선교사님들을 위해 | 구체적인 내용
```

**JSON**
```json
[
  {"title": "가족 건강을 위해", "content": ""},
  {"title": "교회 부흥을 위해"}
]
```

## 성경 업로드 형식

한 줄에 하나, 또는 `말씀 | 참조` 형식

```
항상 기뻐하라 쉬지 말고 기도하라 | 데살로니가전서 5:16-18
여호와는 나의 목자시니 내가 부족함이 없으리로다 | 시편 23:1
```
